# Mumbai Housing Market Explorer

## About the Project

This project explores publicly available Mumbai housing data to understand
patterns in property prices and how factors such as location, area, and BHK
configuration relate to the housing market. The project uses Python and pandas
for data cleaning and exploration, with visual analysis to be added in later
stages. The findings may be useful to prospective buyers, sellers, real-estate
analysts, researchers, and anyone interested in understanding Mumbai's housing
market.

Dataset
*Dataset:* Mumbai House Prices
*Source:*Kaggle


Questions

1. How does property price vary across different Mumbai locations?

2. What is the relationship between property area and property price?

3. How does property price vary across different BHK configurations?
